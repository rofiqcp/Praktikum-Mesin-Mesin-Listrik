# Jobsheet Lengkap 16 — Responsi Akhir

Gunakan dokumen ini untuk latihan station P16.

## Station A — Transformator
Kerjakan satu soal rasio/regulasi/efisiensi dan satu soal line–phase atau vector group. Jelaskan arti hasilnya.

## Station B — Motor DC
Hitung back-EMF atau daya mekanik dari data yang diberikan. Jelaskan hubungan arus, torsi, rpm, dan beban.

## Station C — Motor Induksi
Hitung `Ns`, slip, frekuensi rotor, atau daya tiga fasa. Interpretasikan satu kurva torsi-slip atau performa beban.

## Station D — Logika Kendali
Dari state table atau diagram yang diberikan, jelaskan latching, interlock, permissive, timer, serta invariant yang tidak boleh dilanggar.

## Station E — Motor 1 Fasa / Mesin Sinkron
Pilih salah satu:
- jelaskan mekanisme pembentukan torsi awal motor satu fasa dan hubungan `C`–`Xc`;
- hitung hubungan rpm–frekuensi mesin sinkron dan interpretasikan OCC/V-curve.

## Station F — Data
Dari dataset kecil:
1. identifikasi satuan;
2. hitung satu derived metric;
3. temukan satu data yang perlu ditinjau;
4. buat dua hipotesis;
5. tuliskan data tambahan yang dapat membedakan hipotesis;
6. buat kesimpulan dengan confidence level.

## Station G — Program
Jalankan:

```bash
python program/final_bank.py
python program/final_responsi.py
```

Jelaskan bukan hanya angka jawabannya, tetapi juga rumus dan arti fisiknya.
