# Tugas Video 07 — Audit Logika Kendali di Simulator

**Durasi:** 8–10 menit.  
**Fokus:** CADe SIMU/state machine, truth table, test case, dan invariant.

## Isi Wajib

1. Jelaskan beda fokus P6 dan P7.
2. Tampilkan satu truth table latching atau mutual exclusion.
3. Tampilkan state transition table star–delta model.
4. Demonstrasikan simulasi CADe SIMU untuk minimal dua skenario normal.
5. Demonstrasikan minimal dua fault/conflict test pada simulator.
6. Tunjukkan invariant yang diperiksa.
7. Jalankan `control_logic.py` dan bandingkan hasil logikanya dengan simulator.
8. Jelaskan satu bug logika yang mungkin terjadi jika interlock/invariant tidak diperiksa.
9. Tutup dengan tiga kesimpulan.

## Rubrik

| Aspek | Bobot |
|---|---:|
| truth/state table | 20% |
| simulasi | 25% |
| test case | 20% |
| invariant dan analisis | 20% |
| Python dan komunikasi | 15% |

Seluruh demonstrasi detail dilakukan pada simulator/model software.
