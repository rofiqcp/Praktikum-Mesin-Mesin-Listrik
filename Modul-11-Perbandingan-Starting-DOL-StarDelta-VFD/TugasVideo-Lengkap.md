# Tugas Video Lengkap 11

Gunakan file ini bersama `TugasVideo.md`.

Video 8–10 menit membandingkan DOL, star–delta, dan VFD dari sisi performa.

Wajib menampilkan ketiga program:

```bash
python program/starting_compare.py
python program/vfd_ramp.py
python program/decision_matrix.py
```

Jelaskan perbedaan arus awal, torsi awal, waktu akselerasi, konsep V/f, torque margin, dan pengaruh perubahan ramp. Ubah satu parameter, bandingkan hasil sebelum/sesudah, lalu buat decision matrix untuk satu studi kasus.

Kesimpulan harus menjelaskan mengapa metode dengan arus paling rendah belum tentu merupakan pilihan terbaik untuk semua beban.

Penilaian: konsep 25%, program 25%, perbandingan 30%, komunikasi 10%, kesimpulan 10%.
