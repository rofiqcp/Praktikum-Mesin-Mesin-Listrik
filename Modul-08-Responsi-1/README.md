# Panduan Responsi 1 — P08

P08 adalah evaluasi integrasi P1–P7 dan tidak menambah teori baru.

## Urutan Belajar

1. Baca `Materi.md` untuk ruang lingkup.
2. Gunakan `Formula-Ringkas.md` untuk mengingat persamaan inti.
3. Latihan `Bank-Soal-P1-P4.md`.
4. Latihan `Bank-Soal-P5.md`.
5. Latihan `Bank-Soal-P6.md`.
6. Jalankan `program/responsi_quiz.py` untuk latihan interaktif.
7. Jalankan `program/practice_generator.py` untuk mengecek beberapa contoh numerik.
8. Kerjakan `Project.md` dan `Project-Simulasi.md` sesuai arahan dosen.

## Kompetensi Utama

Responsi menilai kemampuan:

- memilih rumus;
- menjaga satuan;
- membaca data dan grafik;
- menjelaskan sebab-akibat;
- membedakan model dan hasil eksperimen;
- membaca truth/state table;
- menemukan pelanggaran invariant;
- menjelaskan jawaban secara lisan.

## Pola Jawaban

Gunakan pola:

```text
konsep -> diketahui -> rumus -> hitung -> makna -> validasi
```

## Pembagian Pos yang Disarankan

| Pos | Materi | Bentuk |
|---|---|---|
| 1 | P1–P3 | konsep + hitung trafo |
| 2 | P4–P5 | data/grafik motor DC |
| 3 | P6 | Ns, slip, line–phase |
| 4 | P7 | truth/state table |
| 5 | Integrasi | quiz + tanya jawab |

## Output

Mahasiswa membawa hasil latihan, output program, dan catatan kesalahan yang ditemukan selama latihan. Fokus responsi adalah pemahaman, bukan hafalan urutan.
