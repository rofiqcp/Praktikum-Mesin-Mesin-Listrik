# Project 08 — Responsi Integratif P1–P7

Project ini menggantikan TugasVideo pada P8.

Gunakan `Project-Simulasi.md` sebagai panduan lengkap project dan `README.md` sebagai indeks responsi.

## Tantangan

Kelompok menyusun paket integrasi yang berisi:

1. satu kasus transformator atau motor DC berbasis data;
2. satu kasus motor induksi dasar;
3. satu challenge truth/state table dari P7;
4. verifikasi menggunakan program yang tersedia pada P1–P7;
5. minimal satu grafik;
6. minimal lima test case untuk bagian logika;
7. validasi satuan dan kewajaran hasil;
8. presentasi dan tanya jawab individual.

## Deliverable

- ringkasan konsep;
- perhitungan manual;
- dataset;
- output program;
- grafik;
- truth/state table;
- daftar test case;
- hasil bug hunt/validasi;
- kesimpulan berbasis angka.

## Rubrik

| Komponen | Bobot |
|---|---:|
| konsep dan perhitungan | 25% |
| validasi data | 15% |
| program dan grafik | 20% |
| state/test case | 20% |
| analisis kesalahan | 10% |
| presentasi | 10% |

P8 tidak menambah teori baru; seluruh challenge berasal dari P1–P7.
