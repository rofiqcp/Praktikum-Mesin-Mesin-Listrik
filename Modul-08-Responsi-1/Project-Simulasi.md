# Project Simulasi P08

Project ini melengkapi `Project.md` dan difokuskan pada data serta simulasi.

## Paket A — Perhitungan

Pilih dua dataset dari materi P1–P6. Tampilkan diketahui, rumus, perhitungan manual, verifikasi program, grafik, dan validasi.

## Paket B — State Review

Ambil satu state machine dari P7. Buat truth/state table, lima test case, dan daftar invariant. Bandingkan expected result dengan simulator.

## Paket C — Bug Hunt

Dosen memberi satu artefak yang sengaja salah: CSV, perhitungan, grafik, atau state table. Temukan minimal dua kesalahan, jelaskan dampaknya, dan tampilkan perbaikan.

## Deliverable

- `README.md`;
- file perhitungan;
- dataset;
- program;
- screenshot grafik/simulasi;
- test case;
- kesimpulan.

## Presentasi

8–10 menit per kelompok, diikuti pertanyaan individual.

## Rubrik

Konsep/perhitungan 25%, validasi 15%, program/grafik 20%, state/test case 20%, bug hunt 10%, presentasi 10%.
