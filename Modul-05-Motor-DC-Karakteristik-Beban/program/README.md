# Program P05 — Analisis Karakteristik

## File

- `data_dc.csv`: dataset contoh;
- `dc_characteristic.py`: membaca CSV, menghitung daya/efisiensi, dan membuat grafik;
- `dc_pwm.m`: contoh komputasi GNU Octave/MATLAB.

## Python

```bash
python dc_characteristic.py
```

Program cocok dijalankan dari VS Code atau terminal. Untuk Google Colab, upload `data_dc.csv` dan `dc_characteristic.py` ke folder kerja yang sama lalu jalankan script.

## Output yang Dipakai di Laporan

- tabel hasil perhitungan;
- grafik speed terhadap torsi/load;
- grafik efisiensi;
- catatan data yang perlu divalidasi.

## Eksperimen

Duplikasi dataset sebelum mengubahnya. Ubah satu variabel/parameter pada satu eksperimen agar pengaruhnya dapat dianalisis dengan jelas.

Semua nilai contoh pada folder ini adalah dataset/model pendidikan, bukan rating universal motor.
