# Running P10

Dari root repository:
```bash
python Modul-10-Motor-Induksi-Uji-Beban-Efisiensi-PF/program/induction_load_analysis.py
python Modul-10-Motor-Induksi-Uji-Beban-Efisiensi-PF/program/load_sweep_summary.py
```

File CSV harus berada di folder yang sama dengan script. Jalankan baseline sebelum mengubah dataset. Simpan salinan dataset untuk setiap eksperimen agar hasil dapat direproduksi.

Output yang dicatat: jumlah baris, arus rata-rata, PF, rpm, torsi, titik arus maksimum, PF maksimum, torsi maksimum, dan rpm minimum.
