# Jobsheet 15 — Integrasi Data

Gunakan materi P15 dan dataset pada folder `program/` untuk latihan analisis.

## Tugas
1. Identifikasi kolom dan satuan data.
2. Bandingkan data dengan nilai acuan.
3. Hitung besaran turunan yang relevan.
4. Jalankan program Python dan Node yang tersedia.
5. Buat tiga grafik.
6. Tulis dua kemungkinan penjelasan untuk setiap penyimpangan utama.
7. Tulis data tambahan yang diperlukan.
8. Buat kesimpulan dan keterbatasan analisis.

## Program
```bash
python program/analyze_lab_csv.py
python program/multi_machine_diagnostics.py
node program/report.js program/lab_data.csv
```

## Output
Data dictionary, tabel hasil, grafik, analisis, dan kesimpulan.
