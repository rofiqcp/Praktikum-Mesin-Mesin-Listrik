# Software Praktikum

- CADe SIMU: simulasi rangkaian kontaktor/relay (latching, forward-reverse, star-delta).
- GNU Octave/MATLAB: perhitungan dan plot karakteristik mesin.
- Python 3 + Jupyter/Google Colab: analisis data pengukuran dan simulasi numerik.
- OpenModelica (opsional): simulasi dinamik mesin listrik yang lebih mendalam.
- Node.js: CLI/pipeline pengolahan CSV dan pembuatan ringkasan hasil uji.

Semua modul menyediakan minimal satu program yang dapat dijalankan dan data contoh agar praktikum dapat dipelajari sebelum masuk ke hardware.
